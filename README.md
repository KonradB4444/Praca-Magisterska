# AI Assistant

A conversational medical assistant developed as part of a master's thesis. The application combines a machine learning model with an LLM-powered interface to support risk assessment for patients with systemic vasculitis.

## Running locally

1. Clone the repository.
2. Install the required Python dependencies.
3. Start the application:

```bash
streamlit run app_ui.py
```

The application will open automatically in your default web browser.
